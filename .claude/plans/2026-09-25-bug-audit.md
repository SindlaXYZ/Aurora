# Bug audit — findings and fix plan

> Full-codebase bug audit of `src/`, `src/templates/`, `src/Resources/`, `composer.json` and the CI workflow.
> **Nothing was fixed** — this document only lists the defects and proposes the order and shape of the fixes.
>
> Legend for confidence: **[E]** confirmed by execution (throwaway script against PHP 8.4 / Doctrine ORM 3.7 / Symfony 8
> components), **[R]** confirmed by reading the code, **[P]** plausible (depends on runtime configuration).
>
> `php -l` passes on every file in `src/` and `tests/`; all findings below are runtime / logic defects.

## 0. Summary

| Priority | Count | Theme |
|---|---|---|
| P0 — broken for every host app | 9 | Missing service definitions, Composer hook failure, fatal DQL functions, broken routes, removed Symfony/Doctrine APIs |
| P1 — wrong results / security | 18 | Minifier corrupts output, VAT math, IP spoofing, SW caches private pages, DQL injection, crypto |
| P2 — edge cases / robustness | ~30 | Date edge cases, type errors on bad input, temp-file leaks, CI gaps |
| P3 — low / cosmetic | ~15 | Minor inconsistencies, dead code |

Each fix must follow `.claude/CLAUDE.md` (English only, `#[DataProvider]`, Yoda, strict comparison) and ship with a
regression test in the mirrored `tests/` directory.

## 1. P0 — Broken for every host application

### 1.1 Almost all `aurora.*` service ids are commented out [R]
- `src/Resources/config/services.yaml:114-232` — `aurora.twig.utility`, `aurora.client`, `aurora.ip`, `aurora.io`, `aurora.git`,
  `aurora.helper`, `aurora.pwa`, `aurora.sanitizer` (and the rest of the Utils block) are commented out; no other file defines them.
- Still referenced by:
  - `PWAController.php:30` (`aurora.pwa`) → `/manifest.json`, `/sw.js`, `/favicon.ico` return 500.
  - `OutputSubscriber.php:118` (`aurora.sanitizer`), `UtilityExtension.php:30,153,219,267`, `MiscProcessor.php:40`, `AuroraPWA.php:29`
    (`#[Autowire(service: 'aurora.git')]`), `TestController.php:40`.
  - `ComposerCommand.php:161,349,365,381` (`aurora.io`) — see 1.2.
  - README setup (`twig.globals.aurora: '@aurora.twig.utility'`, `$auroraClient: '@aurora.client'`) → container compilation fails.
- **Fix:** restore the definitions (FQCN as primary id + `aurora.*` aliases, `public: true` where fetched via `->get()`), or register
  `Sindla\Bundle\AuroraBundle\Utils\` via `resource:` and add the aliases. Add a kernel-boot test asserting every id used in `src/` exists.

### 1.2 `composer update` fails in every host that uses the documented hooks [R]
- `src/Command/ComposerCommand.php:381` — `_cleanUpAndChecks('postUpdate')` always calls `$this->container->get('aurora.io')` (missing,
  see 1.1) → `ScriptHandler.php:123` throws → non-zero exit. `postInstall` fails too once `public/static/compiled/*` exists (`:365`).
- `ComposerCommand.php:192-199` — `_updatePHPUnit()` downloads an unpinned phar from the network with no error handling and writes into
  `vendor/phpunit/` (absent with `--no-dev`) → offline / firewalled / no-dev installs break.
- `ComposerCommand.php:91` — `trim($input->getOption('action'))` with `strict_types=1` → TypeError when `--action` is missing [E].
- **Fix:** use `new AuroraIO()` (or the restored service); remove `_updatePHPUnit()` or make it opt-in and non-fatal; cast the option.

### 1.3 Undeclared runtime dependencies [R]
- `composer.json` — `ScriptHandler` needs `symfony/process`; `CommandMiddleware` needs `doctrine/doctrine-bundle`; commands need
  `symfony/console`; `LazyEntityCommand` needs `doctrine/annotations`; `PWAController`/`AuroraGit` need `ext-apcu`.
- A skeleton-only host fatals in the post-install hook.
- **Fix:** add the missing packages to `require` (or `suggest` + guard), and drop the `doctrine/annotations` usage (see 3.10).

### 1.4 DQL functions fatal on Doctrine ORM 3 [E]
- `src/Doctrine/DQL/PostgreSQL/DateTrunc.php:29` — `parse()` lacks `: void` → fatal "must be compatible" on class load.
- `src/Doctrine/DQL/MySQL/Year.php:12`, `Month.php:12`, `Timestamp.php:12` — `public string $date` receives an AST `Node`; without
  `strict_types` it is stringified and `YEAR(e.d)` fails with "No metadata for DQL alias".
- **Fix:** add `: void`; type the property as `Node|string` (or untyped, like the PostgreSQL siblings). Add a DQL→SQL test per function.

### 1.5 `/aurora/compiled/{fileName}` always returns 500 [R]
- `src/Resources/config/routes/routes.yaml:150` — `'aurora.controller.compiled:cssJsFiles'` uses a single colon; Symfony 8 only accepts `::`.
- **Fix:** `'aurora.controller.compiled::cssJsFiles'`.

### 1.6 `aurora:composer` name collision [R]
- `src/Command/LazyEntityCommand.php:25` declares the alias `aurora:composer`, which is `ComposerCommand`'s name. Resolution depends on
  service order; after `Application::all()` the Composer hook may run `LazyEntityCommand` (no `--action`) and fail.
- **Fix:** remove the alias.

### 1.7 Calls to non-existent / removed APIs [R/E]
- `UtilityExtension.php:268`, `MiscProcessor.php:41` — call `AuroraClient::ip()`, which does not exist (it lives on `AuroraIP`).
- `MiscProcessor.php:23` — `__invoke(array $record)` is incompatible with Monolog 3 (`LogRecord`) → TypeError on every log call.
- `OwnableSubscriber.php:84,90` — `TokenInterface::isAuthenticated()` (removed in Symfony 6) and return type `?User` pointing to a
  non-existent class → every persist/update by a logged-in user crashes [E].
- `MigrationFactoryDecorator.php:8,30` — `ContainerAwareInterface` removed in Symfony 7 → decorator silently does nothing [E].
- `LocaleSubscriber.php:56,124` — helpers typed with the removed `GetResponseEvent` [E].
- `BaseRepository.php:243-250` — `truncate()` uses `$this->_em`, `Ns:Short` aliases and `executeUpdate()` (all removed in ORM 3 / DBAL 4);
  the `Error` bypasses `catch (\Exception)` and leaves the transaction open.
- `WebTestCaseMiddleware.php:77` — `new UsernamePasswordToken($user, $password, 'database', $roles)` uses the pre-6.0 signature [E].
- `TestController.php:40` — `$this->get()` was removed from `AbstractController`.
- **Fix:** migrate each call site to the current API; for the test helper prefer `$client->loginUser($user)`.

### 1.8 Streamed responses crash with the minifier enabled [E]
- `src/EventSubscriber/OutputSubscriber.php:86-95,115-119` — only `BinaryFileResponse` is skipped; for `StreamedResponse` /
  `StreamedJsonResponse` / `EventStreamResponse`, `getContent()` is `false` → `setContent()` throws `LogicException`, `strtr(false)` TypeError.
- **Fix:** skip when `$response instanceof StreamedResponse || $response instanceof BinaryFileResponse || false === $response->getContent()`.

### 1.9 Trait method-name collisions (copy-paste) [E]
- `ECommerce/BankTransfer/BankTransferAmountTrait.php:74-94` — methods named `get/setCardVatPercentage`, `get/setCardVatAmount`.
- `ECommerce/BankTransfer/BankTransferDiscountTrait.php:32` — method named `calculateCashDiscountAmount`.
- Using the BankTransfer trait next to the Card/Cash one is a fatal trait collision; the BankTransfer accessors don't exist.
- **Fix:** rename to `BankTransfer*` (BC note in the changelog).

## 2. P1 — Wrong results and security

### 2.1 HTML minifier corrupts output [E]
- `AuroraSanitizer.php:88-108` (`minifyHTML`, used by `OutputSubscriber` when `aurora.minify.output` is on):
  - every `\n` becomes a space → `// comment\ncode` swallows the following JS; ASI-dependent JS becomes a syntax error;
  - `<pre>` / `<textarea>` whitespace lost; `>\s+<` → `><` glues inline elements (`<b>Hello</b> <i>World</i>` → "HelloWorld").
- `OutputSubscriber.php:87,116` — only exact content-type strings are excluded, so `application/json` / `text/plain; charset=UTF-8` are
  minified too (`{"a":"x   y"}` → `{"a":"x y"}`).
- `AuroraSanitizer.php:512-520` (`dispatchLoopShutdown`) strips `//text` and closing tags inside `<script>`/`<pre>`.
- **Fix:** minify only when the media type is `text/html`; protect `script|style|pre|textarea` blocks with placeholders; collapse
  whitespace between tags to one space instead of removing it; keep newlines inside scripts.

### 2.2 CSS / JS minifiers corrupt data [E]
- `AuroraSanitizer.php:220` — hex shortening has no end boundary and class `[a-f0-6]` → `#11223344` → `#12344`.
- `AuroraSanitizer.php:207` — strips spaces around `+`/`-` → `calc(100% - 10px)` becomes invalid.
- `AuroraSanitizer.php:247` — `console\.[^;]+;` stops at `;` inside strings and has no `\b` (`myconsole.foo();` removed).
- `AuroraSanitizer.php:456-458` (`minifyJSV2`) — collapses whitespace inside string literals.
- `AuroraSanitizer.php:52` + `AuroraMatch.php:64` — `cssMinify()` rewrites root-relative and fragment URLs
  (`url(/img/a.png)` → `url(/css//img/a.png)`, `url(#grad)` → `url(/css/#grad)`); `str_ireplace($basename, ...)` hits the whole path.
- `UtilityExtension.php:479,484` — `'| {'` → `'\n{'` (single quotes: literal backslash-n) and `' || '` rewrites alter regexes/strings.
- **Fix:** delegate JS to `tedivm/jshrink` and CSS to `matthiasmullie/minify` (both already dependencies); drop the ad-hoc regexes.

### 2.3 VAT / amount math is wrong [R/E]
- `AmountTrait.php:40-43`, `PriceTrait.php`, `PricePerItemTrait.php`, `Card/CardAmountTrait.php`, `Cash/CashAmountTrait.php` —
  `calculate*WithoutVat()` subtracts VAT from the **net** amount (net 100, VAT 19 → 81); `'0.00'` is truthy so the `else` branch never
  runs, and that branch divides the VAT amount instead of the gross. `BankTransferAmountTrait` uses `WithVat` correctly.
- All Amount/Price traits (~line 51) — `bcdiv(pct, 100, 2)` truncates 5.5% → 5%; `bcmul(..., 2)` truncates instead of rounding.
- PHP default VAT `'0.00'` vs DB default `'19.00'`; `*_without_vat` column comment says "with VAT".
- **Fix:** `without = with − vat` when `with` is non-zero (`bccomp`), else `with / (1 + pct/100)`; intermediate scale ≥ 4; half-up rounding.
  Table-driven tests per trait.

### 2.4 Client IP spoofing [E]
- `AuroraIP.php:23-48` — `CF-Connecting-IP` is trusted whenever present and never validated; `X-Forwarded-For` takes the leftmost
  (client-controlled) value. `ip()` can return `<script>…` or any chosen IP → bans / rate limits / BlackHole bypassed; invalid values
  crash `AuroraClient::ip2*` (only `AddressNotFoundException` is caught, `AuroraClient.php:107,122,137,157`).
- `AuroraIP.php:50-51` — `ipIsValid($request->getClientIp())` → TypeError when `getClientIp()` is `null` (CLI, sub-requests) [E].
- `AuroraClient.php:199` — `protocol()` echoes any `X-Forwarded-Proto`.
- **Fix:** rely on `Request::getClientIp()` + Symfony `trusted_proxies`/`trusted_headers`; `filter_var(FILTER_VALIDATE_IP)`; whitelist http/https.

### 2.5 Service worker caches private pages / broken config rendering [R/E]
- `pwa-sw.js.twig:91-121` — every same-origin GET (including navigations and `no-store`/`private` responses) is cached-first until the
  version changes → user A's `/account` served to user B on the same browser.
- `AuroraPWA.php:247-250` + `pwa-sw.js.twig:18,63,76,86` — config concatenated into raw JS: `external_cache: []` → `[//];` (SyntaxError,
  verified with `node --check`); `prevent_cache: []` → `['']` matches everything; quotes/slashes break the script.
- `pwa-sw.js.twig:79` — `prevent_cache` uses `url.match()` on the full URL, so `/q` matches `/quality`.
- `pwa-main.js.twig:33-41` — `controllerchange` reload also fires on the very first install (`clients.claim()`), losing form input.
- `AuroraPWA.php:214-216` — `addslashes()` + Twig `js` escaping → `Don\'t` shown.
- **Fix:** network-first for `request.mode === 'navigate'`, never cache `no-store`/`private`; pass config via `json_encode`; anchor
  `prevent_cache` on `pathname`; reload only if a controller existed before registration; drop `addslashes`.

### 2.6 Build version / git hash stuck [R]
- `AuroraGit.php:39-45,122-131` — detached HEAD (CI, tag deploys) → "Undefined array key 2"; packed refs and `.git`-less deploys fall back
  to `dev` / `N/A` → PWA version never changes.
- `AuroraGit.php:113,143` — cache key ignores `$branch`; `new ApcuAdapter('')` (also `AuroraPWA.php:391`, `PWAController`) shares keys
  between apps on the same FPM pool.
- **Fix:** handle bare-SHA HEAD, read `packed-refs`; namespace the adapter and include `$branch` + project root in keys.

### 2.7 DQL injection in `BaseRepository` [R]
- `BaseRepository.php:161,172,180,192,300-389` — operator, JSON key, order field, filter `field`/`alias` are interpolated into DQL and
  parameter names; typical use passes `$request->query->all()`.
- **Fix:** whitelist operators; validate fields against `ClassMetadata`; build parameter names from an index.

### 2.8 `BaseRepository::extract()` logic [R]
- AND/OR key ignored; `andWhere` repeated once per attribute on the property; properties without attributes dropped; undefined `type`
  index; `orderBy()` in a loop keeps only the last sort (`addOrderBy`); filter state stored on the shared repository service leaks between
  calls/requests; `ISNULL`/`NOTNULL` wrap non-text columns in `UNACCENT()`.

### 2.9 `--action` dispatches arbitrary methods [E]
- `CommandMiddleware.php:93-108` — only `_`-prefixed names are blocked: `aurora:php-unit --action=databaseDrop` runs
  `doctrine:schema:drop --full-database --force`; `--action=execute` recurses forever.
- **Fix:** allow-list methods declared in `static::class` returning `int`, excluding `Command`/`CommandMiddleware` methods.

### 2.10 `TestController` exposed in all environments [E]
- `TestController.php:14-18` + `routes.yaml:1-5` — action taken from the last `/` segment of `getRequestUri()` (query string included) and
  dispatched with `method_exists`: `GET /aurora/test?/__invoke` recurses until OOM; `?/render`, `?/forward` → 500; `?x=1` returns `null`.
- **Fix:** remove the route from the bundle routes (or restrict to `when@dev`) and use an explicit `match`.

### 2.11 BlackHole subscriber turns 404s into 500s and leaks credentials [E]
- `BlackHoleSubscriber.php:67-85` — HttpClient response never consumed → destructor throws on 3xx-5xx/transport errors; call is blocking;
  payload forwards all request headers incl. `Authorization` and `Cookie` to a third-party API.
- **Fix:** try/catch around `getStatusCode()`, short timeout, strip sensitive headers.

### 2.12 Crypto weaknesses [E]
- `AuroraCryptor.php:60,97` — raw password used as key (OpenSSL truncates/pads: different keys decrypt); AES-CTR without MAC is
  malleable (`amount=100` → `amount=900` by bit flipping); `setCipher('aes-256-gcm')` fails (no tag handling).
- `AuroraCryptor.php:156` — `sha256To64Bit` uses `base_convert` (float) → wrong/colliding values above 2^53.
- `AuroraStrink.php:146-160` — `randomString()` uses `mt_rand` with a fixed charset rotation.
- **Fix:** derive key via HKDF/SHA-256; encrypt-then-MAC or GCM with stored tag (versioned payload for BC); `gmp`/`brick/math`;
  `random_int()`.

### 2.13 Secrets in logs [E]
- `ComposerCommand.php:274` — MaxMind key in the query string; the `fopen` failure warning prints the full URL into Composer/CI output.
- **Fix:** Basic auth via HttpClient; never echo the URL.

### 2.14 Coverage badge lies [E]
- `AuroraPHPUnitCodeCoverageBadge.php:397-405` — sums all `//metrics` (project + file + class) → 50% reported as 60%.
- Same file `:13-17,28` — unreadable/truncated `junit.xml` → "passing" badge.
- **Fix:** read `/coverage/project/metrics` only; throw when XML fails to load.

## 3. P2 — Edge cases and robustness

### Dates / calendar
1. `AuroraChronos.php:481-483` — `getUniqueWeeksInRange()` keys by `Y` instead of ISO year `o`: duplicate week 1 across new year and the
   last week of 2024 dropped [E].
2. `AuroraCalendar.php:166` — compares full datetimes; last day lost when end time < start time [E]. Normalise with `setTime(0, 0)`.
3. `AuroraCalendar.php:92` — `$firstDayOfTheWeek` not validated (1–7) [E].
4. `AuroraChronos.php:109-143` — overflow dates accepted (`31.02.2013` → `2013-03-03`), `garbage` → `1970-01-01` [E].
5. `AuroraChronos.php:172-176` — `diffIsHigherThan()` typed `\DateTime`, rejects `DateTimeImmutable` [E].
6. `AuroraChronos.php:389-394` — `monthFromYearAndWeek()` does not validate the week number [E].

### Strings
7. `AuroraStrink.php:344,606-622` — `preg_replace(.../u)` null on invalid UTF-8 assigned to `string` → TypeError [E].
8. `AuroraStrink.php:12` — `if ($string)` drops `"0"` [E].
9. `AuroraStrink.php:385,435` — transliteration map inverted (`?` → `¿`, `ſ` → `F`) [E].
10. `Romanian.php:104` — `usile` → `ușie` (drops `l`); `:84` no word boundary (`postare` → `poștare`); `:49` misses lowercase `fara` [E].
11. `AuroraMatch.php:115` — `passwordStrength()` without `s` flag; `min > max` compile warning [E].

### Arrays / helpers
12. `AuroraArray.php:33`, `AuroraHelper.php:39` — `array_merge` renumbers top-level int keys in dot-path flattening [E].
13. `MetaTrait.php:90-95` — loose `array_search`, `array_splice` with a key as offset, `injectMeta(mixed)` into `array_merge` [E].

### Entities
14. `Identifiable/*NonNullable*.php` — `getId(): ?int` reads uninitialised `int $id` before persist [E]; `*NonAutoincrement` use the option
    key `` '`unsigned`' `` (backticks) so unsigned is never applied [R].
15. `IdentifiableIntNonNullableStrategyCustom.php:15` — `strategy: 'CUSTOM'` without `#[ORM\CustomIdGenerator]` → metadata error [R].

    PasswordUpdated) — `DATETIME_IMMUTABLE` columns with `?DateTimeInterface` setters → `new \DateTime()` fails on flush [E].
17. `TimestampableCreated.php:10`, `TimestampableUpdated.php:12`, `TimestampableDeletedNotNullable.php:11` — `#[HasLifecycleCallbacks]` on a
    trait has no effect; document or move to a listener [R].
18. `TimestampableDeletedMutable.php:37` — `isDeleted()` compares `DateTime == string` → always true for the sentinel [E].
19. `SoftDeleteIndexSubscriber.php:33` — only handles the abstract superclass, not entities using the traits; ignores `fields:` indexes;

26. `AuroraPWA.php:105,121` — `trigger_error(E_USER_NOTICE)` per missing icon → 500 in dev [P].
27. `UtilityExtension.php:137,140,161,173` — `pwa(Request, bool $debug)` needs 2 args while docs call it with 1; `getParameter(...) ?? false`

36. `phpunit.yml:217-327` — badge commit step keyed on `GITHUB_HEAD_REF` + shallow checkout + `rebase` can push merge-commit history into

## 5. Proposed execution order

1. **Restore the container** (1.1, 1.3, 1.5, 1.6) + a kernel-boot smoke test that resolves every `aurora.*` id and every bundle route.
2. **Composer hooks** (1.2, 2.13, 3.20-21) + CI job running the hooks (3.38).
3. **Framework API migrations** (1.4, 1.7, 1.8) — one commit per component, each with a regression test.
4. **Data-correctness** (1.9, 2.3, section 3 dates/strings/arrays/entities) — table-driven tests with `#[DataProvider]`.
5. **Security** (2.4, 2.7, 2.9, 2.10, 2.11, 2.12) — call out BC impact (Cryptor payload format, trait renames) in the changelog.
6. **Output / PWA** (2.1, 2.2, 2.5, 2.6, 3.25-30) — prefer delegating to the existing minifier dependencies.
7. **CI hardening** (3.35-37) and **P3** clean-up.

After each step: run the affected PHPUnit directories and PHPStan level 6 as described in `.claude/CLAUDE.md`.
